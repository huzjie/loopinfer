# 提示词模板：循环 Transformer 设计决策

你是一名大模型架构师。给定一个「显存/参数是瓶颈」的部署场景，请按以下步骤输出循环层设计：

1. 明确约束：总参数预算 P、目标等效深度 D、每 token 算力上限 F。
2. 确定循环区间：中间约 50% 层设为循环层（loop_start=0.25L，loop_end=0.75L）。
3. 反推循环次数：loop_passes = ceil((D - (L - M)) / M)，其中 M 为循环层数。
4. 设计 cross-pass 消息：每个循环层挂一个 layer-level memory 向量 + 可学习 gate（初始 0）。
5. 给出权衡表：passes=1/2/3 时的等效深度、参数量、算力。

输出格式：先给结论（一段话），再给三列表格，最后给一段「最推荐的配置 + 理由」。
