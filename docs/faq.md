# FAQ

**Q: 为什么 generate 输出是乱码？**
A: 参考实现用随机权重，只为验证「链路可跑」。换真实权重（替换 model 层数值）即可产出正常文本。

**Q: 等效深度 48 是不是等于 48 层算力？**
A: 不是。等效深度是「表达能力」口径，算力按实际执行层数（24 + 12*2 = 48 次前向）算。

**Q: 循环层会不会退化？**
A: 不加 cross-pass 消息会退化（收益递减）。本项目默认开启 layer-level memory + gate。

**Q: 怎么对齐官方 Inkling 2 Mini？**
A: config 里 n_experts 改 256、dim 改 64、top_k 保持 8，调度 / 解码逻辑不变。

**Q: 为什么专家数 256 时初始化会慢？**
A: 惰性专家生成解决了这个问题——只生成被路由到的专家。
